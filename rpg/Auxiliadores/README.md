==> barras.py
----> Resumo: Cria barras no terminal para organizar a saida do código

==>Funções:
----> 1) linha(tipo,texto): Cria linhas de 4 tipos diferente [arrow, triangle, maori e else], caso o texto = 0 ele ignora o texto
----> 2) charge(valor): Cria uma barra de carregamento de de 0 a 100
----> 3) box(texto): Cria uma caixa onde o texto fica centralizado  

==================================================================================================================
